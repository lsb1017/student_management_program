## 확정 범위

백업은 지금 백업 → 기존 학원·반 팝업 → 확인 → 자동 PC 저장·Drive 업로드. 기존 ‘오늘도 수고 많으셨어요!’ 문구, 축하만두, 파일명 안내를 보존하고 실행 버튼은 확인으로 표시한다. 학원·반은 파일명에만 반영, 전체 자료 백업 유지. 기본 파일명은 YYYYMMDD_HHMM_학원_반.omrbackup, 같은 분에는 번호 추가, 기존 파일 덮어쓰기 금지. 자동 위치는 data/backups/automatic이다.

학생 등록에서 같은 이름·연락처의 기존 학생 발견 시 기존 학생에게 반 추가 버튼으로 체크한 반을 연결한다. 여러 후보면 학생을 선택한다. 자동 동일인 병합하지 않으며 별도 등록/취소도 유지한다. 기존 학생번호·연락처·성적을 덮어쓰지 않는다. 이 기능은 학생 등록 팝업이며 기존 일괄등록의 명시적 학생번호 연결 방식은 유지한다.

학생 합치기는 학생 조회·추가의 별도 버튼이다. 유지할 학생·옮길 학생을 고르고 삭제 대상 시험명·점수·사유를 본 뒤 확인한다. 기본 선택 취소. 유지할 학생 성적은 보존하고 옮길 학생의 수기 및 중복 시험 기록만 삭제한다. 나머지 OMR은 답안·점수·확정/대기 상태 그대로 유지해 연결하고 두 소속 반을 합친다. 옮긴 성적의 소속은 유지할 학생 기본 반으로 바뀌는 것을 사용자가 승인했다. 옮길 학생 등록은 제거되어 한 학생만 남는다.

삭제 이전 안전 백업은 data/backups/before_student_merge. 백업 실패 시 중단한다. 확인 목록의 fingerprint를 백업 전과 트랜잭션 내부에서 재확인하여 그 사이 자료가 달라지면 취소한다. 삭제와 이동은 단일 트랜잭션, 오류면 전부 롤백한다. 합치기 되돌리기는 전체 안전 백업 복원이며 이후 변경도 되돌아간다.

삭제된 OMR은 실제 바이트를 즉시 제거하지 않고 deleted 상태로 남는다. 합치기에서 정리한 행은 merge_locked_deleted를 표시해 일반 삭제 취소를 막는다. 기존 삭제 이력도 유지할 학생 ID로 연결하며 student_merge 표시로 같은 시험의 활성 OMR·연결된 이전 성적·동시 복구 항목 충돌을 검사한다. 삭제 취소가 중복을 만들면 중단한다.

이전 엑셀 이관 성적(historical_results)은 고유 기록을 이동하고 중복 기록만 확인 목록에 넣어 삭제한다. linked_exam_id로 현재 시험과의 중복도 검사한다. 학생명만으로 시험을 동일하다고 추정하지 않는다. 원본 스캔 이미지 복사나 상시 추가 작업 없이 관계 갱신으로 처리한다.
