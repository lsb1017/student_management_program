만두OMR 1.0.6 변경 사항

1. 지금 백업을 누르면 기존 축하만두·오늘도 수고 많으셨어요 문구의 학원·반 선택창이 표시됩니다. 확인 후 저장 위치 선택 없이 PC 저장 및 Drive 업로드합니다.
2. 파일명은 날짜_시분_학원_반.omrbackup. 같은 분에 다시 저장하면 번호를 붙이며 덮어쓰지 않습니다.
3. 이름·연락처가 같은 기존 학생 발견 시 기존 학생에게 선택한 반을 추가할 수 있습니다. 학생번호·기존 성적은 보존합니다.
4. 학생 합치기: 유지할 학생과 옮길 학생을 선택합니다. 유지할 학생의 성적은 보존하고 옮길 학생의 수기·중복 시험 기록만 삭제합니다. 시험명·점수·사유를 먼저 표시하고 취소가 기본인 확인창에서 동의를 받습니다.
5. 합치기 전 전체 안전 백업을 저장합니다. 삭제·연결 이동·소속 반 통합은 한 번에 처리하며 실패하면 전부 되돌립니다. 이동 OMR의 답안·점수·확정 상태는 유지하고 성적 소속은 유지할 학생의 기본 반으로 바뀝니다.
6. 합친 뒤 삭제 취소가 중복 성적을 만들지 않도록 검사합니다. 합치기에서 정리한 기록은 일반 삭제 취소로 복구하지 않습니다.

검증 338개 통과, 가상 자료 실행파일 검사 통과. 기존 실제 학생·성적은 수정하지 않았습니다.
데이터 구조 10 유지, 기존 백업 호환. 합치기 취소는 합치기 전 전체 백업 복원이 필요하며 이후 작업도 함께 되돌아갑니다.

만두OMR 1.0.6 시작하기

새 폴더에 ZIP 전체를 풀어 실행하세요. 기존 프로그램의 최신 백업을 PC 백업 가져오기로 가져오세요.
연결 설정에서 연구실 Google 계정으로 로그인·승인하면 기본 연구실 백업 폴더로 연결됩니다.
지금 백업 → 학원·반 선택 → 확인 → PC 저장 및 Drive 업로드 순서입니다. 학원·반은 파일명에만 반영하고 전체 자료를 백업합니다.
PC 사본은 data/backups/automatic에 남습니다. 다른 위치에 백업 저장 기능도 유지합니다.
학생 합치기는 학생 조회·추가에서 실행합니다. 삭제 대상 시험명·점수와 유지할 학생을 반드시 확인하세요.
합치기 전 안전 백업은 data/backups/before_student_merge에 저장합니다. 합친 학생 등록은 하나만 남습니다.
Google 연결 정보·실사용 자료는 배포 ZIP에 포함하지 않습니다. 공유는 제한됨으로 유지합니다.
